🌐 **Live Site**: [mary-njiru-dev-portfolio.vercel.app](https://mary-njiru-dev-portfolio.vercel.app/)

## ✨ Features

- **Dynamic Hero Canvas**: Interactive 3D visual graphic overlay featuring smooth CSS gradient masking.
- **Hydration-Safe Responsive Nav**: Mobile drawer menu with mounted state checks to eliminate SSR/hydration mismatches.
- **Interactive Contact Modal**: Integrated contact pop-up powered directly by **EmailJS** for real-time messaging without backend dependencies.
- **Hard-Offset Button System**: Custom, reusable button component system mapping across internal links, external links, and interactive triggers.
- **CSS Modules Architecture**: Modular, scoped styling prioritizing pixel-perfect alignment and system responsiveness.

## 🚀 Getting Started Locally

### 1. Prerequisites
Ensure you have **Node.js 18+** and **npm** installed on your machine.

### 2. Clone the Repository
`git clone https://github.com/Mary-Njiru/dev-portfolio.git`
`cd dev-portfolio`

### 3. Install Dependencies
`npm install`

### 4. Configure Environment Variables
Create a `.env.local` file in the root of your project:
- `NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id`
- `NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id`
- `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key`

### 5. Run the Development Server
`npm run dev`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 📂 Project Structure

- `app/` — Next.js App Router pages and global layout
- `components/` — React UI components (Footer, Header, Hero, Projects, Strip, UI elements)
- `data/` — Project data models and static assets
- `lib/` — Custom hooks and utilities
- `public/` — Static assets (images, PDFs, SVGs)
- `styles/` — Global design system & variables
